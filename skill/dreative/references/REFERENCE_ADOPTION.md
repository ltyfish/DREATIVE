# Reference study and adoption

A supplied reference can mean faithful recreation, a particular interaction, or
general inspiration. Infer from the request; ask only if the ambiguity materially
changes the result. Do not impose cross-domain originality on a requested faithful
recreation. Respect rights separately from visual study.

## Observe before describing

Open the actual site and run the relevant sequence. Record its input, start,
intermediate composition, hold, handoff, and resolved state. Observe mobile too
when adapting its behavior. A screenshot supports composition, not a claim about
timing, reversal, or scroll distance. If the live site is inaccessible, use a
recording and state what could not be tested.

For scouting, use whole experiences (studio portfolios, Awwwards, FWA, Godly)
to find a fitting sequence, then primary documentation or an implementation
article such as Codrops to understand the mechanism. Follow the linked original
site. Galleries and popularity are discovery tools, not evidence of fit.
For worked examples of this translation, use `PRODUCTION_STUDIES.md`. A library
demo answers how an effect works; a complete production also shows what happens
before it, what it enables afterward, and where the experience becomes quiet.

For a specific gap in references, components, asset authoring, or craft guidance,
use `CREATIVE_RESOURCES.md`. Read only the relevant family; do not tour a catalog
before deciding what the project needs.

Keep the useful note short:
`source → observed behavior → adapted property → destination in this project`.
Include what the observation does not establish. No mandatory source-count quota.
Separate inspiration from acquisition: a gallery gives a lead; a component
repository gives implementation; an asset source gives usable material only
under its applicable terms; a skill gives advice. Select the missing output
instead of collecting all four indiscriminately.

## Translate the visual grammar

Preserve the selected reference's decisive relationships: subject scale,
negative space, framing, timing, layer order, and the join between regions.
A palette match cannot compensate for losing the chosen composition or motion.
For inspiration, adapt the principle to the new subject instead of transplanting
the entire combined identity. For a faithful rebuild, assess fidelity directly.

Compare the prototype to the reference at matched viewport and motion states:
start, transformation, and handoff, plus playback. If the strongest property was
not retained, change the implementation or disclose the deviation; do not call
the reference “adopted” because it appears in the plan.

## Code and assets

Use official APIs/downloads or inspect permitted public-page media for discovery.
Follow `MEDIA_SOURCES.md` for acquisition and rights. A page's CSS or media being
downloadable is not an automatic reuse license.

For a copied mechanism record source/license and inspect dependencies, cleanup,
accessibility, resize, and mobile behavior. Use only the relevant primitive from
a component library. Select GSAP, Motion, Anime.js, or native animation according
to ownership needs; installing several does not increase creative quality.

Showcase still uses the reference/asset fields required by its existing
`SHOWCASE.md` contract. Those fields verify declared bindings, not that the
reference was understood or that the result is good.
