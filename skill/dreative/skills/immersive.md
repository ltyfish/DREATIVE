# Immersive

Use when several sections should feel like one continuous environment or
instrument, rather than a stack of unrelated bands.

## Continuity needs one owner, and it has to change

Pick the single *logic* that persists. That is often a thing — geometry, the
product's own state carried forward — but it does not have to be a thing at
all, and the builds that read as stacked bands are usually the ones that assumed
it did. It can be a field the whole route sits inside: grain, dither, particles,
weather, a light that changes as the reader descends. It can be the medium —
resolution, pixel size, focus, a render that assembles and comes apart, so each
section is a state of one image rather than a different picture. It can be a
camera, sections being places in one continuous move. It can be a relay, several
subjects handing to one another, which reads as one place as long as the rule of
the handoff holds even when the thing being handed changes.

One owner means one logic, not one object. Two unrelated continuity ideas
competing across a route read as neither; four subjects passed along one clear
rule read as a single place.

Then make it *do* something across the route. A canvas that is present in every
section but identical in every section is not continuity; it is wallpaper with
good attendance. What makes an environment feel real is that moving through it
changes it, and that the change is caused by where the reader has got to. The
question at each new section is: what has this become, and why here?

There is no right number of transformations. There is a reader who should be
able to tell, without being told, that they have moved.

## Rhythm and exit

An environment with no rest in it stops registering as an environment. Alternate
weight; let quiet sections be quiet while the continuity owner keeps its thread.

Direct task access survives all of this — someone who wants the price or the
button should reach it without touring the world. And persistent elements have
to release before the content that follows arrives, or the environment becomes
an obstruction laid over the page.

Give mobile a bounded form that is a version of the environment, not its
absence.

## How this fails

A hero effect that is abandoned below the fold, which reads as a page that gave
up. An overlay competing with the content it sits on. Continuity asserted by a
repeated badge or a shared canvas rather than by anything actually continuous.
And the safe failure: sections so cautiously connected that the reader never
notices they were meant to be one place.
